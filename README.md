## 📖 О проекте

**Airdrop & Crypto Tracker** — это мощная и удобная панель управления (Dashboard / CRM) для крипто-энтузиастов, ретродроп-хантеров и инвесторов. Приложение помогает структурировать рутину, отслеживать прогресс выполнения заданий, контролировать дедлайны клеймов и автоматически сбрасывать ежедневные активности.

---

## ✨ Ключевые возможности

### 🔐 1. Личный кабинет Администратора (Admin Panel & RBAC)
- **Защита доступа**: добавлять новые проекты, редактировать существующие, удалять проекты и добавлять активности может **только авторизованный администратор**.
- **Данные учетной записи по умолчанию**:
  - **Логин**: `Extazik`
  - **Пароль**: `Gfnhbjn113`
  - **Email для восстановления**: `Extazik113@gmail.com`
- **Восстановление пароля**: 3-шаговая система сброса пароля (Запрос одноразового 6-значного кода подтверждения на Email -> Ввод кода -> Установка нового пароля).
- **Смена пароля в профиле**: администратор может безопасно изменить пароль в окне профиля.
- **Публичный доступ**: обычные пользователи могут просматривать проекты, фильтровать, сортировать, отмечать личные избранные, изучать токеномику и экспортировать календари.

### 🎯 2. Управление проектами и активностями
- **Создание и редактирование проектов**: название, тикер, официальный сайт, логотип (URL или загрузка файла до 2MB), подробное описание (с живым счетчиком до 500 символов), выбор категорий и тегов.
- **Интерактивный чек-лист заданий**: добавление активностей любого типа (*Тестнет*, *Мейннет*, *Стейкинг*, *Ликвидность*, *Торговля*, *Рефералы*, *Социальные сети* и др.) с прямыми ссылками и отметками о выполнении.
- **Инвесторы и раунды**: учет венчурных фондов с разделением по тирам (**Tier 1 / Tier 2**), суммами привлеченных инвестиций в USD и датами раундов.
- **Токеномика**: интерактивная круговая диаграмма (Recharts) с проверкой распределения долей (команда, инвесторы, комьюнити, экосистема, резерв) ровно на **100%**, стандартом токена и общим предложением (Total Supply).

### 🏷️ 3. Статусы и типы наград
- **Цветная система статусов**:
  - 🟡 **Потенциально** (Potential) — проект на ранней стадии.
  - 🟠 **Регистрация** (Registration) — открыта регистрация/вайтлист.
  - 🟢 **Получение** (Claiming) — активна раздача наград (с кнопкой быстрого перехода к Claim URL).
  - 🔵 **Подтверждена** (Confirmed) — аирдроп официально анонсирован.
  - ⚫ **Завершена** (Completed) — раздача завершена.
- **Типы вознаграждений**: Токены (Airdrop), Роли в Discord, Поинты, NFT, Вайтлисты (WL), Амбассадорские программы.

### ⏰ 4. Автоматический ежедневный сброс (03:00 МСК)
- Встроенный серверный планировщик (Cron-механизм), который **каждые сутки в 03:00 по московскому времени (UTC+3)** автоматически обнуляет выполненные чекбоксы у активностей с флагом *«Сброс каждые 24ч»*.
- Модальное окно управления сбросом с живым таймером обратного отсчета, ручной кнопкой принудительного сброса и журналом истории.

### 🔍 5. Фильтры, поиск и умная сортировка
- **Мгновенный полнотекстовый поиск** по названию проекта, тикеру токена (`$MONAD`), описанию и тегам.
- **Гибкая фильтрация**: по статусу наград, типам вознаграждений, уровню прогресса (0-25%, 25-50%, 50-75%, 75-100%, 100%), блокчейну, тиру инвесторов, категории и горящим дедлайнам.
- **Сортировка**: по приоритету, дате добавления, приоритету статуса, прогрессу выполнения задач, сложности и алфавиту.

### 📅 6. Календарь дедлайнов и экспорт
- Помесячный интерактивный **Календарь дедлайнов** регистрации и клеймов.
- Экспорт событий в формат **iCalendar (.ics)** для добавления в Google Calendar / Apple Calendar.
- Выгрузка отфильтрованных проектов в **CSV-таблицу**.

### 📊 7. Дашборд аналитики
- Визуализация распределения проектов по статусам, блокчейнам и категориям.
- Рейтинг топ-фондов по количеству проектов в портфеле.
- Общий расчет метрик: процент выполнения задач, общий объем привлеченных инвестиций, количество избранных проектов.

### 🎨 8. UI / UX и Анимации
- Премиальная тёмная тема в стиле GitHub / Web3 (`#0D1117`, `#161B22`, `#21262D`).
- Плавные анимации появления при скролле (Scroll Reveal) и отзывчивый hover-эффект с физикой пружины (`motion/react`).
- Эффект праздничного конфетти при закрытии всех 100% заданий проекта.
- Полная русская локализация, адаптивность для десктопов, планшетов и смартфонов.

## 🛠️ Стек технологий

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide React (иконки).
- **Анимации & Графика**: `motion/react`, `recharts`, `canvas-confetti`.
- **Backend**: Node.js, Express, tsx.
- **Хранилище данных**: Встроенная JSON-база данных с атомарной записью в файловую систему (`/data/projects.json`, `/data/reset_logs.json`).

## 📦 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/airdrop-crypto-tracker.git
cd airdrop-crypto-tracker
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки
```bash
npm run dev
```
Приложение запустится по адресу: **http://localhost:3000**

### 4. Сборка для продакшена
```bash
npm run build
npm start
```

## 🔌 API Эндпоинты

### 🛡️ Аутентификация администратора
| Метод | Эндпоинт | Описание | Защита |
|---|---|---|---|
| `POST` | `/api/auth/login` | Авторизация администратора (логин/пароль) | Публичный |
| `GET` | `/api/auth/verify` | Проверка валидности сессии (Bearer Token) | Токен |
| `POST` | `/api/auth/forgot-password` | Запрос 6-значного кода восстановления на email | Публичный |
| `POST` | `/api/auth/reset-password` | Подтверждение кода и установка нового пароля | Публичный |
| `POST` | `/api/auth/change-password` | Смена пароля администратора | Токен |

### 📁 Проекты и активности
| Метод | Эндпоинт | Описание | Защита |
|---|---|---|---|
| `GET` | `/api/projects` | Получить список всех проектов | Публичный |
| `POST` | `/api/projects` | Создать новый проект | 🔐 Только Extazik |
| `PUT` | `/api/projects/:id` | Обновить данные проекта | 🔐 Только Extazik |
| `DELETE` | `/api/projects/:id` | Удалить проект | 🔐 Только Extazik |
| `POST` | `/api/projects/:id/activities` | Добавить активность к проекту | 🔐 Только Extazik |
| `PUT` | `/api/activities/:id/toggle` | Переключить статус выполнения задания | Публичный |
| `POST` | `/api/favorites/:id` | Добавить проект в избранное | Публичный |
| `DELETE` | `/api/favorites/:id` | Удалить проект из избранного | Публичный |
| `POST` | `/api/reset-daily-progress` | Принудительно запустить сброс заданий (03:00 МСК) | Публичный |
| `GET` | `/api/reset-logs` | Получить историю сбросов | Публичный |
