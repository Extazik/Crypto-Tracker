# Towns Protocol Airdrop Bot (Multi-Language)

Этот бот собирает информацию о новых раздачах криптовалют с популярных агрегаторов (**Airdrops.io**, **AirdropAlert**, **CoinMarketCap Airdrops**) и отправляет актуальные данные в чат Towns Protocol в ответ на команду пользователя. Бот поддерживает автоматический перевод текстов на различные языки и умную расстановку статусных эмодзи.

---

## 🚀 Возможности бота

* **Командный режим (Command Only):** Бот работает по запросу и не требует привязки к конкретному ID канала. Он автоматически определяет чат, в котором была вызвана команда, и отвечает туда же.
* **Мульти-парсинг:** Одновременный сбор данных с трех ведущих платформ по аирдропам.
* **Автоматический перевод:** Перевод всех деталей раздачи (статусы, награды и пошаговые задания) на язык, указанный пользователем.
* **Интеллектуальные эмодзи статусов:**
  * ✅ Для **подтвержденных** проектов (`Confirmed` / `Подтвержденный`).
  * ❓ Для **потенциальных** раздач (`Potential` / `Потенциальный`).
* **Мультиязычность:** Вывод отчета на любом нужном языке с помощью ISO-кода (например, английский, испанский, русский и т.д.).

## 🛠 Установка и запуск локально

1. Убедитесь, что у вас установлена среда **Bun** (https://bun.sh/).
2. Распакуйте архив с ботом.
3. Установите зависимости командой:
   ```bash
   bun install
   ```
4. Запустите бота в режиме разработки:
   ```bash
   bun run dev
   ```

---

## ☁️ Развертывание на Render.com

1. Загрузите файлы проекта в ваш репозиторий на GitHub.
2. Авторизуйтесь на [Render.com](https://render.com) и создайте новый **Web Service**, подключив ваш репозиторий.
3. Укажите параметры сборки и запуска:
   * **Build Command:** `bun install`
   * **Start Command:** `bun start`
4. Добавьте необходимые переменные окружения в настройках сервиса (например, `JWT_SECRET` и `APP_PRIVATE_DATA` из панели разработчика Towns).

---

## 💬 Команды бота в чате

Для получения актуальной информации по дропам используйте команду `/drop`, указав (при необходимости) двухбуквенный код нужного языка:

* `/drop` — выведет сводку на **русском языке** (по умолчанию).
* `/drop en` — выведет сводку на **английском языке**.
* `/drop es` — выведет сводку на **испанском языке**.
* `/drop fr` — выведет сводку на **французском языке**.
